## 🚀 Featured Project

### 🎟️ [TicketFlow](https://github.com/jihoo414-tech/TicketFlow)

**공연 좌석을 선착순으로 예매하는 서비스**

대기열 입장부터 좌석 선점과 예매까지 구현하며, 동시에 들어오는 요청 속에서도 좌석 점유 규칙을 지키는 방법을 다룹니다.

- **좌석 정합성** · 회원과 좌석 행을 정해진 순서로 잠가 중복 점유와 회원별 제한을 처리합니다.
- **동시성 검증** · 실제 MySQL과 Testcontainers를 사용해 경합 상황을 테스트합니다.
- **성능 개선** · 좌석 조회 범위를 구역으로 나누고, 부하 테스트로 개선 전후를 비교했습니다.
- **설계 기록** · 불변식, 경쟁 상황, 기술 선택의 근거를 문서로 남겼습니다.

[개발 이야기](https://github.com/jihoo414-tech/TicketFlow/blob/main/docs/story.md) · [AWS 성능 측정](https://github.com/jihoo414-tech/TicketFlow/blob/main/docs/performance/aws-report.md) · [설계 결정 기록](https://github.com/jihoo414-tech/TicketFlow/tree/main/docs/adr)
